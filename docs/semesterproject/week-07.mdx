## Context lost bereik op

Context maakt een waarde beschikbaar voor een onderliggende componentboom zonder elke tussenlaag props te laten doorgeven.

```tsx
type FavoritesContextValue = {
  favorites: Movie[];
  toggleFavorite: (movie: Movie) => void;
};

const FavoritesContext = createContext<FavoritesContextValue | null>(null);
```

Gebruik Context niet automatisch voor alle state. State die maar één component nodig heeft, blijft lokaal.

## Een veilige custom hook

```tsx
export const useFavorites = () => {
  const context = useContext(FavoritesContext);
  if (!context) {
    throw new Error("useFavorites moet binnen FavoritesProvider gebruikt worden");
  }
  return context;
};
```

De hook centraliseert de controle en geeft componenten een duidelijke API.

## Server state

Films van een API zijn geen eigendom van de interface. TanStack Query bewaart querystatus, cache en vernieuwing. Een query key identificeert de data.

```tsx
const moviesQuery = useQuery({
  queryKey: ["movies", searchTerm],
  queryFn: () => getMovies(searchTerm),
});
```

Alle waarden waarvan het request afhangt, horen in de query key.

### Checkpoint

Classificeer elke waarde als lokale UI-state, URL-state, gedeelde clientstate of server state. Leg uit waarom de filmresultaten niet in FavoritesContext horen.
