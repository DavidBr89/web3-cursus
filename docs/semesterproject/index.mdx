## Doel

In dit traject bouwen we gedurende twaalf weken aan één full-stackapplicatie. Iedere week introduceert een afgebakend thema dat onmiddellijk wordt toegepast in React Bios.

De bestaande cursuspagina's blijven de theoretische referentie. Dit afzonderlijke traject verbindt die theorie met de live demo, oefeningen en opeenvolgende versies van het semesterproject.

## Werkwijze per week

Iedere week volgt hetzelfde ritme:

1. Activeer de voorkennis en formuleer het probleem dat we willen oplossen.
1. Bestudeer het nieuwe concept aan de hand van een klein, geïsoleerd voorbeeld.
1. Bouw de oplossing tijdens de live demo in React Bios.
1. Laat studenten het concept zelfstandig toepassen of uitbreiden.
1. Bespreek de code en controleer of studenten hun keuzes kunnen verklaren.

De lector bouwt de applicatie tijdens de lessen stapsgewijs op. Iedere week vertrekt van de code die studenten in de vorige week zelf hebben gemaakt.

## Opbouw

| Blok | Weken | Resultaat |
| --- | --- | --- |
| JavaScript en TypeScript | 1-2 | Een stevige taalbasis voor moderne webapplicaties |
| Reactfundamenten | 3-4 | Een componentgebaseerde, interactieve interface |
| Een volledige React-applicatie | 5-8 | API-data, routes, gedeelde state en gevalideerde formulieren |
| Backendontwikkeling | 9-10 | Een REST API met Express, TypeScript en Prisma |
| Full-stackintegratie | 11-12 | Veilige authenticatie en samenwerking tussen frontend en backend |

## Evaluatie doorheen het traject

Controleer niet alleen of de applicatie werkt. Laat studenten ook:

- de uitvoer of toestand voorspellen voordat zij code uitvoeren;
- uitleggen waarom een component, hook, route of middleware nodig is;
- een kleine wijzigingsvraag uitvoeren zonder de oplossing opnieuw te genereren;
- loading-, fout- en randgevallen aantonen;
- verbanden leggen tussen frontend, HTTP-verzoek, backend en databank.
