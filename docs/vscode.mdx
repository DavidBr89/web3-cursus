## Onze ontwikkelomgeving

Tijdens Web 3 gebruiken we **Visual Studio Code** (VS Code) als geïntegreerde ontwikkelomgeving. We gebruiken dezelfde editor tijdens de lessen, demo's en oefeningen. Zo vind je de gebruikte menu's, commando's en sneltoetsen altijd op dezelfde plaats terug. Je bent vrij om een andere IDE te gebruiken maar hier is er geen ondersteuning voor tijdens de lessen.

VS Code is gratis en beschikbaar voor Windows, macOS en Linux. De editor ondersteunt de talen en hulpmiddelen die we in dit vak nodig hebben, waaronder JavaScript, TypeScript, React, Node.js en Git.


## Downloaden en installeren

Download VS Code uitsluitend via de officiële website:

**[Visual Studio Code downloaden →](https://code.visualstudio.com/Download)**

De website biedt een geschikte installer voor jouw besturingssysteem:

- **Windows:** download de *User Installer* voor x64;
- **macOS:** kies de versie die bij je processor past (*Apple silicon* of *Intel chip*);
- **Linux:** kies het pakket voor je distributie, bijvoorbeeld `.deb`, `.rpm` of Snap.

Doorloop na het downloaden de installatie met de standaardinstellingen. Vink de optie **ADD to PATH** aan als deze vermeld staat in de installer, dit zorgt ervoor dat je straks het `code` commando kunt gebruiken in de terminal/cmd.

## VS Code openen vanuit de terminal

Tijdens de lessen openen we projecten regelmatig vanuit een terminal, Command Prompt of PowerShell. Daarvoor gebruiken we het commando `code`.

### Het commando eenmalig instellen

#### Windows

Vink tijdens de installatie van VS Code de optie **Add to PATH** aan. Heb je VS Code al geïnstalleerd, voer dan de installer opnieuw uit en activeer deze optie. Sluit daarna alle geopende terminals en open Command Prompt of PowerShell opnieuw.

#### macOS

1. Open VS Code.
2. Open het Command Palette met `Cmd + Shift + P`.
3. Zoek naar **Shell Command: Install 'code' command in PATH**.
4. Voer het commando uit en open daarna een nieuw terminalvenster.

#### Linux

Wanneer je VS Code via het officiële `.deb`- of `.rpm`-pakket, Snap of je package manager installeert, wordt het `code`-commando normaal automatisch aan `PATH` toegevoegd. Open na de installatie een nieuw terminalvenster.

### De huidige map openen

Navigeer eerst in je terminal naar de map die je als project wilt openen. Voer daar vervolgens dit commando uit:

```shell
code .
```

De punt `.` betekent **de huidige map**. VS Code opent die map als workspace, waardoor alle bestanden en submappen zichtbaar worden in de Explorer.

Een volledig voorbeeld:

```shell
cd Documents/web3
code .
```

Je kunt ook rechtstreeks een specifieke map meegeven:

```shell
code mijn-react-project
```

<aside className="courseCallout courseCallout--warning">

<strong className="courseCallout__title">Wordt het commando niet herkend?</strong>

Sluit je terminal volledig en open hem opnieuw. Controleer daarna met `code --version` of het commando beschikbaar is. Werkt het nog steeds niet, voer dan de stappen voor jouw besturingssysteem hierboven opnieuw uit.

## Extensies voor Web 3

Extensies voegen ondersteuning toe voor de technologieën en werkafspraken die we tijdens Web 3 gebruiken. Open het extensieoverzicht via het pictogram **Extensions** in de zijbalk of met:

- `Ctrl + Shift + X` op Windows en Linux;
- `Cmd + Shift + X` op macOS.

Zoek een extensie steeds op naam en controleer ook de naam van de uitgever. Installeer alleen de extensies die hieronder worden vermeld.

### Te installeren

| Extensie | Uitgever | Waarom gebruiken we deze? |
| --- | --- | --- |
| [ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) | Microsoft | Toont problemen en mogelijke fouten in JavaScript-, TypeScript- en React-code rechtstreeks in de editor. |
| [Prettier - Code formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) | Prettier | Formatteert code automatisch en zorgt dat iedereen dezelfde consistente opmaak gebruikt. |
| [ES7+ React/Redux/React-Native snippets](https://marketplace.visualstudio.com/items?itemName=dsznajder.es7-react-js-snippets) | dsznajder | Voegt handige afkortingen toe waarmee je onder andere snel een React-component kunt aanmaken. |
| [Bruno](https://marketplace.visualstudio.com/items?itemName=bruno-api-client.bruno) | Bruno | Laat je HTTP-requests versturen, collecties beheren en onze REST API testen zonder VS Code te verlaten. |
| [Prisma](https://marketplace.visualstudio.com/items?itemName=Prisma.prisma) | Prisma | Geeft syntax highlighting, formatting en ondersteuning voor Prisma-schema's tijdens het backendgedeelte. |

### Optioneel
