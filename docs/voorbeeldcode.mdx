## De voorbeeldcode gebruiken

Gebruik de repository om code uit een les opnieuw te bekijken, te vergelijken of verder te onderzoeken. De voorbeeldcode vervangt niet het zelfstandig maken van de Classroom50-oefeningen en het project.

Bekijk steeds de `README` en kies indien nodig de branch of tag die overeenkomt met de juiste les.
