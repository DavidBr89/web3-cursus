## Waar staan we in het verhaal?

Met state kan onze bioscoopapplicatie een gekozen genre, favoriete film of aantal tickets onthouden. Er verandert alleen nog niets zolang de bezoeker geen actie kan uitvoeren. Nu verbinden we knoppen, invoervelden en andere browser-events met de functies die onze state aanpassen.

Een klik op “Voeg ticket toe” verhoogt bijvoorbeeld niet zelf de state. De knop veroorzaakt een event, onze event handler beslist wat dat event betekent en de state-update zorgt daarna voor een nieuwe render.
