## Leerdoelen

Na deze opdracht kun je een componentboom ontwerpen, props correct typeren, composition via `children` toepassen, lijsten met stabiele keys renderen en conditionele UI uit data afleiden.

## Situatie

De startersrepository bevat getypte data voor films, genres en vertoningen. Iedere volgende React-opdracht bouwt verder op deze Cinema App. Wanneer een nieuwe Classroom50-repository gebruikt wordt, bevat de starter minstens het verwachte resultaat van de vorige mijlpaal.

## Starterscode

De Classroom50-repository bevat een Vite React-TypeScriptproject, Tailwindconfiguratie, lege componentbestanden en lokale filmdata in een vereenvoudigde TMDB-vorm. Je kan de centrale data en types ook afzonderlijk downloaden:

## Opdrachten

1. Teken vóór het coderen de componentboom in de `README`.
2. Bouw een `PageHeader`, `MovieList`, `MovieCard`, `MovieMetadata` en een herbruikbare `Badge`.
3. Geef filmgegevens via correct getypte props van parent naar child.
4. Render de collectie met `map` en kies een stabiele key uit de data.
5. Toon conditioneel leeftijdsinformatie, genres en de status van een film.
6. Toon een passende lege toestand wanneer er geen films zijn.
7. Gebruik `children` voor minstens één layoutcomponent.
8. Vermijd gedupliceerde JSX en muteer de startdata niet.

Gebruik Tailwind voor een verzorgde responsive layout, maar de beoordeling focust op de componentgrenzen en gegevensstroom.

## Randgevallen

Controleer minstens een ontbrekende optionele beschrijving, een film met meerdere genres, een lege lijst en twee films met dezelfde titel maar verschillende id’s.

## Oplevering

Push de werkende React-app, de componentboom en een korte motivatie voor minstens twee componentgrenzen. Commit en push regelmatig.

## Wat moet je kunnen uitleggen?

- welke component eigenaar is van de lijst;
- waarom props alleen van parent naar child stromen;
- waarom je gekozen keys stabiel zijn;
- welke UI je berekent in plaats van bewaart;
- wanneer je composition verkoos boven extra props.
