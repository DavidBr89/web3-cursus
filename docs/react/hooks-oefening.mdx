## Opdrachten

1. Focus het filmzoekveld via een correct getypte DOM-ref.
2. Maak een `useOnlineStatus`-hook rond browser-events met symmetrische setup en cleanup.
3. Toon de verbindingsstatus op twee plaatsen en verklaar waarom beide hookaanroepen hun eigen state hebben.
4. Synchroniseer één relevante browser-API met de huidige pagina en ruim het Effect correct op waar nodig.
5. Bouw een tweede custom hook voor herbruikbare Cinema App-logica zonder globale state te verbergen.
6. Herken en verwijder een meegeleverd Effect dat gefilterde films naar state kopieert.
7. Controleer setup en cleanup in Strict Mode.

Gebruik geen `useMemo` of `useCallback` tenzij je een gemeten probleem en de reden schriftelijk kunt aantonen.

## Oplevering

Push de volgende Cinema App-mijlpaal en een korte beschrijving van de setup/cleanupcyclus. Vermeld ook waarom één Effect uit de starter overbodig was.

## Wat moet je kunnen uitleggen?

- state tegenover refs;
- wanneer een Effect werkelijk nodig is;
- waarom cleanup vóór een nieuwe setup kan lopen;
- waarom een custom hook logica maar geen gedeelde state oplevert;
- hoe de Rules of Hooks in je code zichtbaar zijn.
