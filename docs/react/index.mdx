## Doel

In dit gedeelte bouwen we stap voor stap een bioscoopwebapplicatie. We starten niet onmiddellijk met hooks en packages. Bij iedere stap vertrekken we van een probleem dat ontstaat wanneer de applicatie groeit. Daarna bekijken we welk React-concept ons helpt om dat probleem op te lossen.

Het doel is dat je niet alleen weet **hoe** je iets met React schrijft, maar ook **waarom** je bijvoorbeeld components, state, routing of een externe package gebruikt.

## Van een klassieke website naar React

De eerste websites bestonden vooral uit HTML-documenten. Wanneer een bezoeker op een link klikte, vroeg de browser een volledig nieuwe pagina aan de server. De server bouwde de HTML op en de browser toonde die pagina. Voor een website met hoofdzakelijk tekst en enkele formulieren werkt dat nog steeds prima.

Onze bioscoopapplicatie vraagt meer. Een bezoeker wil films filteren, details openen, een vertoning kiezen en een reservatie invullen. Bij iedere kleine actie een volledige pagina opnieuw laden voelt traag en zorgt ervoor dat tijdelijke informatie op het scherm gemakkelijk verloren gaat.

Met gewone JavaScript kunnen we de bestaande pagina aanpassen:

```javascript
const lijst = document.querySelector("#films");

films.forEach((film) => {
  const item = document.createElement("li");
  item.textContent = film.titel;
  lijst.appendChild(item);
});
```

Dit werkt voor een klein voorbeeld. Zodra meerdere stukken van de pagina afhangen van dezelfde gegevens, moeten we echter zelf bijhouden wat veranderd is en welke DOM-elementen opnieuw aangepast moeten worden. Filmkaartjes, filters, een teller en een detailpaneel raken dan snel met elkaar verweven.

React laat ons de omgekeerde redenering gebruiken: we beschrijven hoe de interface eruitziet voor de **huidige gegevens en toestand**. Wanneer die toestand verandert, zorgt React ervoor dat de interface opnieuw overeenkomt met onze beschrijving.

<aside className="courseCallout courseCallout--note">

<strong className="courseCallout__title">React is niet altijd nodig</strong>

Voor een eenvoudige, grotendeels statische website kan gewone HTML, CSS en JavaScript voldoende zijn. React wordt interessant wanneer een interface uit veel herbruikbare onderdelen bestaat en regelmatig moet reageren op veranderende data en gebruikersinteracties.
</aside>

## De rode draad: onze bioscoopapplicatie

We bouwen de applicatie niet in één keer. Elk hoofdstuk voegt iets toe omdat de vorige versie tegen een nieuw probleem botst:

1. **Components:** dezelfde filmkaart en knop komen op meerdere plaatsen terug. We splitsen de interface op in herbruikbare bouwblokken.
2. **State:** een gekozen genre en aantal tickets moeten op het scherm kunnen veranderen zonder de pagina opnieuw te laden.
3. **Interactiviteit:** knoppen, invoervelden en events verbinden het gedrag van de bezoeker met onze state.
4. **Hooks:** componenten krijgen meer gedrag en moeten soms samenwerken met iets buiten React.
5. **Routing:** het filmaanbod, een filmdetail en de reservatie moeten elk een eigen URL krijgen en bruikbaar blijven met de terugknop.
6. **Formulieren:** een reservatie bevat meerdere velden, validatie en foutmeldingen die samen beheerd moeten worden.
7. **Axios:** de filmgegevens komen uiteindelijk niet meer uit een lokale array maar uit de backend.
8. **TanStack Query:** serverdata kan laden, mislukken en verouderd raken. We willen requests en caching niet in iedere pagina opnieuw bouwen.

Aan het einde hebben we niet zomaar losse React-technieken gezien. We hebben gezien hoe de architectuur van een frontend meegroeit met de problemen van een echte applicatie.

## Wat is React dan precies?

React is een library voor het bouwen van gebruikersinterfaces. We bouwen een interface op uit herbruikbare components die hun weergave baseren op properties en state. React neemt niet de volledige applicatiearchitectuur over: voor onder meer routing, formulieren en serverdata kiezen we later gerichte oplossingen wanneer onze applicatie die nodig heeft.

## Het opzetten van een nieuw project

Het makkelijkste om React aan te leren is om onmiddellijk een React projet op te zetten met een tool genaamd [Vite](https://vite.dev). We gebruiken tijdens de lessen `yarn` om nieuwe React projecten aan te maken met het volgende commando:

<aside className="courseCallout courseCallout--note">

<strong className="courseCallout__title">Opmerking</strong>

Voer dit commando uit in opdrachtprompt (CMD) onder Windows om problemen te vermijden met Powershell. Dit commando maakt een nieuwe map aan met de naam die je gekozen hebt, dus doe dit in een map waarin je jouw React projecten wilt bijhouden.
</aside>

```console
$ yarn create vite
```

Dit geeft een gelijkaardige interactieve CLI zoals de volgende afbeelding:

![](/img/react/yarnvite.png)

Kies hier de volgende zaken:

1. **Project name:** Kies hier de **naam-van-jouw-project**. Het beste is dat je dit doet a.h.v. kebab-casing.
1. **Select a framework:** Kies hier voor **React**
1. **Select a variant:** Kies hier voor **TypeScript + React Compiler** (Belangrijke stap!)
1. **Use Vite 8 beta (Experimental):** Kies hier voor **No**
1. **Install with yarn and start now?** Kies hier voor **No**

<aside className="courseCallout courseCallout--danger">

<strong className="courseCallout__title">Belangrijk</strong>

We gebruiken [React Compiler](https://react.dev/learn/react-compiler) (redelijk nieuwe feature) in onze nieuw aangemaakte React projecten. Basically gaat dit ervoor zorgen dat React zelf gaat beslissen wanneer er optimalisaties moeten gedaan worden. Dit betekent dus dat we **nergens in onze code `useCallback` of `useMemo` nodig hebben**. Let hier ook op voor jullie project.
</aside>

We hebben nu onze eerste React applicatie aangemaakt. Vite kon ook voor ons automatisch alle dependencies installeren en de development server opstarten. We hebben hier gekozen om dit niet te doen, we gaan deze stappen manueel doen om te tonen hoe dit werkt.

Voor de volgende stap moeten we in de nieuw aangemaakte map `eerste-react-project` navigeren en de dependencies installeren:

```console
$ cd eerste-react-project
$ yarn install
# Kan ook afgekort door enkel yarn te gebruiken
```

<aside className="courseCallout courseCallout--note">

<strong className="courseCallout__title">Opmerking</strong>

Wanneer je voorbeeldcode (GitHub) downloadt en lokaal op je eigen computer wil uitvoeren, zal je telkens opnieuw de dependencies moeten installeren.
</aside>

Nadat alle dependencies geinstalleerd zijn door het `yarn` of `yarn install` commando uit te voeren kunnen we nu de React applicatie opstarten

```console
$ yarn dev
```

![](/img/react/yarndev.png)

Vite zal nu automatisch een development server opstarten en dit standaard op [http://localhost:5173](http://localhost:5173).

![](/img/react/reactstart.png)

## Code editor

Je mag zelf kiezen welke IDE je gebruikt om jouw React applicaties te ontwikkelen. Ik gebruik tijdens de lessen steeds VS Code met een aantal handige extensies.

### Linting

Code linters detecteren problemen in je code terwijl je aan het programmeren bent, zodat je fouten vroegtijdig kan opsporen en corrigeren. [ES Lint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint) is zo'n populaire, open-source linter voor JavaScript/TypeScript.

### Formatter

Een formatter is een tool die de opmaak van je code automatisch aanpast zodat deze consistent en leesbaar blijft volgens vaste regels.

[Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) is zo'n formatter. Het zorgt ervoor dat je code automatisch netjes wordt geformatteerd volgens vooraf ingestelde en configureerbare regels. Wanneer je Prettier uitvoert, worden bijvoorbeeld tabs omgezet naar spaties en worden inspringing, aanhalingstekens en andere opmaak aangepast volgens de gekozen configuratie.

Het is ideaal om Prettier automatisch te kunnen laten uitvoeren bij het opslaan (format on save) en/of automatisch bij het plakken van code (format on paste). Je kan dit instellen als volgt:

1. Druk op `CTRL` (Windows) of `CMD` (Mac) `+ SHIFT + P`
1. Typ `settings`
1. Druk op `ENTER`
1. Typ in de zoekbalk `format on`
1. Zorg ervoor dat de optie `Format on save` / `Format on paste` aangevinkt staat

![](/img/react/prettier.png)

### Snippets

Snippets zijn vooraf gedefinieerde stukjes code die je snel kan invoegen via een korte afkorting, zodat je sneller en efficiënter kan programmeren. Een handige extensie die we kunnen installeren om gebruik te maken van snippets om onze React components vlug aan te maken is [ES7+ React/Redux/React-Native snippets](https://marketplace.visualstudio.com/items?itemName=dsznajder.es7-react-js-snippets).
