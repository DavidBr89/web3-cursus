## Voor je indient

Bereid eerst de volgende informatie voor:

- je voornaam en achternaam;
- je HoGent-mailadres;
- je traject;
- de titel van je project;
- een voldoende duidelijke projectbeschrijving.

Bij **Traject** kies je één van de volgende opties:

- Web 3 en Cloudontwikkeling;
- Web 3 zonder Cloudontwikkeling;
- Cloudontwikkeling zonder Web 3.

Beschrijf bij **Projectbeschrijving** minstens wat je applicatie doet, voor wie ze bedoeld is en welke belangrijkste functionaliteiten je wil uitwerken. Een korte omschrijving zoals “ik maak een webshop” is niet voldoende.

<aside className="courseCallout courseCallout--note">

<strong className="courseCallout__title">Bevestig de afspraken</strong>

Voor je het formulier verzendt, bevestig je dat:

- je geen onderwerp gekozen hebt dat tijdens de lessen volledig werd uitgewerkt;
- je het voorstel aanpast wanneer een lector je daarover opmerkingen mailt;
- je alle ingediende code zelf moet kunnen uitleggen en aanpassen;
- een duidelijke en regelmatige commitgeschiedenis verplicht is.
</aside>

## Na het indienen

Na het indienen is je voorstel **in principe goedgekeurd**. Je ontvangt dus niet noodzakelijk een afzonderlijke bevestigingsmail.

Alleen wanneer een aanpassing nodig is, stuurt een van de lectoren je een e-mail met opmerkingen. Controleer daarom regelmatig je HoGent-mailbox. Hoor je niets van de lectoren, dan mag je ervan uitgaan dat je onderwerp goedgekeurd is en hoef je niets te veranderen.
