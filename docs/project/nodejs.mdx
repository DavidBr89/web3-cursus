## Inleiding

Neem je Web 3 op zonder Cloudontwikkeling in hetzelfde semester, dan bouw je een volwaardige frontend in React met een beperkte backend in Node.js. Je werkt volledig in TypeScript en kiest zelf een geschikt onderwerp.

## Doelstellingen

Met dit project toon je aan dat je:

- een volwaardige React-frontend kan bouwen die communiceert met een beperkte Node.js-backend;
- kan werken met context, state, routing en formulieren;
- zoeken, filteren en pagineren op serverniveau kan verwerken in de frontend;
- een gesimuleerde betalingsflow kan integreren;
- frontend en backend afzonderlijk kan deployen met een correcte CORS-configuratie;
- een duidelijke commitgeschiedenis kan opbouwen in Classroom50;
- zowel frontend als backend kan verdedigen en toelichten.

## Functionele vereisten

### Data en CRUD

- Gebruik meerdere entiteiten met minstens één 1-N- of N-N-relatie.
- Gebruik een MySQL-databank in combinatie met Prisma.
- Voorzie per relevante entiteit een volledige CRUD-flow: lijst, detail, toevoegen, bewerken en verwijderen.
- Gebruik formulieren met duidelijke validatie en foutmeldingen.

### Authenticatie en rollen

- Implementeer registratie en inloggen.
- Je kan hiervoor JWT gebruiken of een geschikte externe authenticatieoplossing kiezen.
- Gebruik minstens twee rollen, bijvoorbeeld `user` en `admin`.
- Pas de gebruikersinterface en toegelaten acties aan volgens de rol van de gebruiker.

### Zoeken en betalingen

- Voorzie zoeken, filteren en pagineren op serverniveau en toon de resultaten correct in de frontend.
- Implementeer een volledige gesimuleerde betaalflow met Mollie of Stripe.
- Verwerk de bijhorende webhook in de Node.js-backend.

### Gebruikerservaring

- Gebruik minstens één niet-triviale React context, bijvoorbeeld voor authenticatie, een winkelmandje of permissions.
- Voorzie duidelijke toestanden voor `loading`, `error`, `empty` en `success`.
- Zorg voor een consistente layout en verzorgde styling.
- Voorzie minstens één exportfunctie, bijvoorbeeld naar CSV of PDF.

## Technische vereisten

- React met TypeScript en Vite;
- een consequente feature-first frontendstructuur met duidelijke grenzen tussen applicatieconfiguratie, routes, features, gedeelde UI en infrastructuur;
- geen gebruik van `any`;
- React Router;
- React Hook Form of Formik;
- Fetch API of Axios met foutafhandeling;
- een Node.js-backend met correcte HTTP-statuscodes en aandacht voor security;
- MySQL met Prisma;
- frontend en backend afzonderlijk deployen;
- CORS correct configureren;
- Classroom50 voor de repository en opvolging;
- een duidelijke en regelmatige commitgeschiedenis.

De hoofdstukken onder [Node.js en Express](/node/) vormen de technische basis voor de backend. Je moet niet alleen kunnen aantonen dat de endpoints werken, maar ook kunnen uitleggen hoe een request door routes, middleware, validatie, services en Prisma reist en waar authenticatie en autorisatie afgedwongen worden.

## Verdediging

Aan het einde volgt een individuele verdediging van ongeveer **40 à 45 minuten**. Je verdedigt zowel de frontend als de backend, licht de architectuur toe, legt geselecteerde code uit en voert mogelijk een live aanpassing uit.

Wie de eigen code niet kan uitleggen, kan niet slagen voor Web 3. Wanneer het resultaat van de eerste kans onvoldoende is, vindt de tweede examenkans plaats in **augustus/september**. De concrete opdracht en afspraken worden door de lector meegedeeld.
