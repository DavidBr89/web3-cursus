## Evaluatieproject Web 3

Voor de evaluatie van Web 3 bouw je een volwaardige frontend in React en TypeScript. Je past de technieken uit de lessen samen toe in één professionele en voldoende uitdagende webapplicatie.

Welk traject je volgt, hangt af van de OLOD’s die je dit semester opneemt.

| Traject | Backend | Repository en opvolging |
| --- | --- | --- |
| Web 3 en Cloudontwikkeling | De C#-backend uit Cloudontwikkeling | Classroom50 |
| Web 3 zonder Cloudontwikkeling | Een beperkte Node.js-backend | Classroom50 |

## Wat geldt voor iedereen?

Ongeacht het traject:

- bouw je een verzorgde React-frontend in TypeScript;
- gebruik je de technieken die tijdens de lessen behandeld werden;
- werk je via Classroom50 en moet je een duidelijke en regelmatige commitgeschiedenis hebben;
- deploy je frontend en backend afzonderlijk;
- configureer je CORS correct;
- moet je alle ingediende code begrijpen en kunnen uitleggen;
- volgt op het einde een individuele verdediging met mogelijke live aanpassingen.

<aside className="courseCallout courseCallout--danger">

<strong className="courseCallout__title">Je code kunnen verdedigen</strong>

Wie de eigen code niet kan uitleggen of aanpassen, kan niet slagen voor het betreffende OLOD. Het doel is niet alleen dat de applicatie werkt, maar ook dat je aantoont dat je ze zelf beheerst.
</aside>

## Afzonderlijke eindresultaten

Web 3 en Cloudontwikkeling zijn twee afzonderlijke OLOD’s. Ook wanneer je één geïntegreerd project maakt, krijg je voor ieder OLOD een afzonderlijk eindresultaat. Een onvoldoende voor het ene OLOD verhindert dus niet dat je voor het andere OLOD een eindresultaat krijgt of slaagt.

De tweede examenkans vindt plaats in **augustus/september**. De concrete opdracht en afspraken voor die tweede kans worden door de lectoren meegedeeld.

## Projectonderwerp

Je onderwerp moet voldoende mogelijkheden bieden om alle functionele en technische vereisten uit te werken. Onderwerpen die volledig tijdens de lessen gebruikt worden, zoals de bioscoopapplicatie, mogen niet als project hergebruikt worden.
