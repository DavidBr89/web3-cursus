Welkom bij de online cursus Web 3. Je leert hier stap voor stap hoe je met TypeScript en React een volledige webapplicatie bouwt. Deze cursus bouwt verder op de JavaScript kennis die je opgedaan hebt tijdens Web 2.

## Jouw lector

Ik ben David Breckx, lector Web 3. Bij vragen of opmerkingen kan je mij met je HoGent-e-mailadres mailen via [david.breckx@hogent.be](mailto:david.breckx@hogent.be).

## Studiewijzer en evaluatie

De officiële studiewijzer van Web 3 vind je terug op **Orion**. Raadpleeg die studiewijzer voor de formele afspraken en evaluatiegegevens van dit opleidingsonderdeel.

De evaluatie bestaat uit een omvangrijk project waaraan je gedurende het semester werkt. Afhankelijk van je traject maak je dit project alleen voor Web 3 of combineer je het met **Cloudontwikkeling**. Voor deze evaluatie is er een tweede examenkans in **augustus/september**.

## Organisatie van de lessen

Web 3 bestaat iedere week uit twee lesblokken:

- **2 uur op de campus:** we behandelen de nieuwe onderwerpen samen en bouwen voorbeelden uit;
- **2 uur online:** je werkt aan de oefeningen en verwerkt de leerstof zelfstandig.

Tijdens het online lesblok ben ik beschikbaar via **Microsoft Teams** voor vragen en extra uitleg.

De cursus bouwt laag per laag op. Elk onderdeel combineert heldere theorie, gerichte codevoorbeelden en oefeningen waarmee je controleert of je het concept echt beheerst.

## Zo gebruik je deze cursus

Lees de hoofdstukken in de volgorde van het leerpad. Voer codevoorbeelden zelf uit, voorspel eerst het resultaat en open pas daarna een uitklapbare oplossing.

<aside className="courseCallout courseCallout--tip">

Je mag tijdens oefeningen AI gebruiken, tenzij je lector anders aangeeft. Je blijft verantwoordelijk voor iedere regel code: je moet de uitvoer kunnen voorspellen, keuzes kunnen verantwoorden en de oplossing zelfstandig kunnen aanpassen.
