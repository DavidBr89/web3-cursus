## Voorkennis: Git en GitHub

Git en GitHub worden in deze cursus als voorkennis beschouwd. Je leerde er al mee werken in vorige opleidingsonderdelen. Controleer vóór de eerste les of Git beschikbaar is:

```shell
git --version
```

Het commando moet een versienummer tonen. Controleer ook of je nog toegang hebt tot je GitHub-account. De basiswerking van repositories, commits, branches, pull en push wordt in deze cursus niet opnieuw behandeld.

### Oefeningen via Classroom 50

Voor de oefeningen gebruiken we [Classroom 50](https://classroom50.org), de open-source tegenhanger van GitHub Classroom. GitHub Classroom werd stopgezet en is daarom niet langer beschikbaar voor het beheren van nieuwe oefeningen.

Via Classroom 50 krijg je voor iedere oefening een eigen GitHub-repository. Daarin werk je de opdracht uit en bewaar je jouw voortgang met Git en GitHub. De concrete werkwijze om een oefening te accepteren en in te dienen wordt tijdens de lessen uitgelegd.

<aside className="courseCallout courseCallout--warning">

<strong className="courseCallout__title">Zelf oefenen, maar niet vrijblijvend</strong>

De oefeningen zijn bedoeld om de leerstof van Web 3 zelfstandig in te oefenen. Jouw code wordt daarbij standaard niet automatisch op inhoudelijke juistheid gecontroleerd. Je blijft dus zelf verantwoordelijk voor het testen en begrijpen van je oplossing.

Er wordt voor de punten wel nagegaan of je actief aan de oefeningen werkt en je voortgang via Classroom 50 bijhoudt.

</aside>

## Checklist

Je ontwikkelomgeving is klaar wanneer de volgende zaken in orde zijn:

- Visual Studio Code is geïnstalleerd;
- het commando `code --version` werkt;
- de verplichte VS Code-extensies zijn geïnstalleerd;
- `node --version` en `npm --version` tonen een versienummer;
- `yarn --version` toont een versienummer;
- `git --version` toont een versienummer;
- je hebt toegang tot je GitHub-account;
- je beschikt over een recente webbrowser met Developer Tools.
